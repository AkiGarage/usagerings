# Code of Conduct

Be respectful, constructive, and specific. Harassment, discrimination, threats, spam, and disclosure of another person's private information are not acceptable.

Maintainers may edit or remove content and restrict participation when necessary to protect the community.

For conduct concerns that can be discussed without personal information, open a GitHub issue. If a concern is sensitive, request a private contact channel without posting details. Security vulnerabilities should follow [SECURITY.md](SECURITY.md).
